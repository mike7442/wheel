# reference/prototype — Arduino-прототип, который доказал путь FFB

Это **не рабочий код** текущего руля. Это первоисточник решения: именно здесь
было показано, что Dirt Rally 2.0 отдаёт force feedback обычным
DirectInput-эффектом через vJoy, и что этот эффект можно поймать из Python.

Без этой папки решение «vJoy + pyvjoy callback», а не «парсить телеметрию»,
висит в воздухе: остаётся только «так было написано в документации».

Оригинал лежал в `attempt_2\sim-racing-wheel-main\sim-racing-wheel-main`
(скачанная чужая заготовка + свои скрипты), 30 файлов, 178 МБ, из них 178 МБ —
логи. Сюда перенесён весь код (40 КБ) и маленькие логи; полный набор логов —
в релизе, см. §4.

## 2. Что именно доказано этими файлами

Из лога `ffb_log_2026-08-28_18-25-48.txt` (игра: `colin mc rae dirt 2`):

| Факт | Значение |
|---|---|
| Эффект | один, `EffectType=1` (**constant force**) |
| Magnitude | `-10000…+10000` |
| Обновление | медиана **10 мс**, p90 11 мс → **100 Гц** |
| Device gain / effect gain | 255 / 255 |
| Periodic / condition | нет |
| Всего обновлений за сессию | 32314, из них ненулевых 29966 |

То есть весь FFB DR2 — одно число, 100 раз в секунду. Отсюда и весь текущий
путь: `game → vJoy → pyvjoy callback → magnitude → torque`.

Для контраста: в логах других игр встречаются condition-эффекты (`condX`,
spring), поэтому `vjoy_ffb.py` не универсален — он про constant force.

## 3. Чем это отличается от `scripts/vjoy_ffb.py`

`Simple_FFB.py` обрабатывал **только** `reptype=5` (set constant force). Если
игра останавливала эффект, на моторе оставался последний magnitude — то есть
руль продолжал тянуть после выхода из заезда.

В `vjoy_ffb.py` это закрыто: обрабатываются `reptype=10` (EFF_STOP), `11`
(block free), `12` (device control 2/3/4/5) и `13` (gain). Это единственное
принципиальное изменение; остальное — замена Arduino на MM32 и PWM на момент.

## 5. Как снять такой лог заново

1. `logg_into_file.py` — путь к порту и имя файла правятся в начале файла.
2. Запустить, затем игру, зайти в заезд, покрутить руль.
3. В лог пишутся строки вида:

```
[18:25:51.295] reptype=5 | ebi=1 | data={'const': {'EffectBlockIndex': 1, 'Magnitude': 0}}
[18:25:51.295] reptype=1 | ebi=1 | data={'effect': {'EffectType': 1, ...}}
```

Разбор: `reptype` — тип отчёта (см. `REFERENCE.md` §6.3 в репозитории
`sim-wheel`), `ebi` — индекс блока эффекта, `Magnitude` — то самое число.

## 6. Статус

Код не поддерживается и не запускается. Он оставлен как доказательство и как
справка: если текущий путь сломается или понадобится новая игра, здесь видно,
как снимать и читать FFB-отчёты.
